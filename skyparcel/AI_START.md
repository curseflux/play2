# Opening message for your coding assistant

Copy this when you start your timer:

```text
I have 60 minutes for the Skyparcel practice assessment in this folder.
Help me in small stages. Prioritize simple, correct code and partial credit.

Read START.md, RULES.md, and engine.py. Do not read _staff/, hidden data,
authoring witnesses, or solutions in other folders. Edit only submission.py
and any new policy helpers; do not change the simulator, grader, or cases.

First, without implementing a policy, summarize the observation fields,
exact update order, action-trigger rule, cargo-dependent physics, collision
inequalities, station processing, termination, and scoring. Flag any missing
information or inconsistency instead of guessing. Then wait for my next stage.

For later changes, keep each edit narrow, explain what changed, run the
relevant visible checks, and report measured results. Do not replace a
working algorithm with a more complex one without explaining the need.
```

Keep the first response short enough that you can check it against the engine.
Decide the algorithm yourself or ask for a comparison before implementation.
The purpose of this mock is to measure whether small delegated tasks save time.
